# Kiterow's Aegisub Scripts

Guía de uso de los scripts de Kiterow para Aegisub, con ejemplos y referencias de los módulos compartidos.

- [Leer la guía](https://kiterowx.github.io/Kite-Aegisub-Scripts-Guide/).
- [Repositorio de scripts](https://github.com/Kiterowx/Kite-Aegisub-Scripts).

## Vista local

```text
python -m pip install -r requirements.txt
python -m mkdocs serve
```

## Compilar

```text
python -m mkdocs build --strict --clean
```

El contenido está en `docs/` y la navegación en `mkdocs.yml`. Cada script tiene una página con sus operaciones y ejemplos.
