# Kiterow's Aegisub Scripts

Scripts de Kiterow para timing, carteles, karaoke y edición de subtítulos en Aegisub. Cada guía explica las entradas, los controles y el resultado con ejemplos.

Empieza por la [instalación](installation.md). Las macros aparecen en **Automation**; las acciones directas se agrupan bajo `: Kite Hotkeys :`.

## Elegir una herramienta

| Trabajo | Scripts |
| --- | --- |
| Timing y revisión | [Chrono Suite](suites/chrono-suite.md), [Wave2json](lite/wave2json.md), [Pointiac](lite/pointiac.md) |
| Edición de carteles | [Rhea Signs](suites/rhea-signs.md), [Allure](standard/allure.md), [Cliptomaniac](standard/cliptomaniac.md) |
| Color y textura | [Zheus Colormanager](suites/zheus-colormanager.md), [Gradient Row](standard/gradient-row.md), [AddTexture](standard/addtexture.md) |
| Máscaras y vectorización | [AutoMask](standard/automask.md), [PNG2ASS](standard/png2ass.md) |
| Movimiento y desenfoque | [Moka Motion](standard/moka-motion.md), [AutoBlur](standard/auto-blur.md) |
| Karaoke y animación | [Alecto KFX](standard/alecto-kfx.md), [Obake](standard/obake.md), [Zagreo Glyphs](standard/zagreo-glyphs.md), [Macaria Revert](standard/macaria-revert.md) |
| Selección y campos | [Selesub](standard/selesub.md), [Field Group Manager](standard/field-group-manager.md) |
| Capturas y recortes de vídeo | [Snapshoter](standard/snapshoter.md), [Social Clip](standard/social-clip.md) |
| Atajos y preferencias | [Hotkeys](lite/hotkeys.md) |

Los módulos son bibliotecas compartidas. Se instalan en `include/kite` y su documentación contiene ejemplos de Lua para quienes desarrollan scripts.
